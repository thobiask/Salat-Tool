# SALAT - Software Accountability for Latin America Tool

**Author:** Thobias Karpinski  
**Institution:** Instituto Federal de Santa Catarina (IFSC), Brazil  
**Status:** Research software associated with an accepted paper at Latin.Science 2026 (Latinoware 2026)

## English

### Overview

**SALAT (Software Accountability for Latin America Tool)** is the demonstrative implementation of the **Computational Normative Translation Model (CNTM; Portuguese: Modelo de Tradução Normativa Computacional - MTNC)**, a method for translating open legal standards from Latin American data-protection laws into verifiable, article-traceable software engineering decisions.

The tool converts open legal expressions such as *"appropriate technical measures"* into concrete and defensible engineering decisions. Each control is mapped to a specific legal provision and to recognized technical references, including NIST, OWASP, ISO, and CIS.

### Associated publication

Karpinski, T. **"Legal Software Architecture in Latin America: A Computational Normative Translation Model for Data Protection and Civil Liability Prevention."** Accepted at **Latin.Science 2026, Latinoware 2026**.

The final bibliographic reference and DOI will be added after publication.

### What SALAT includes

- **45 controls** organized into **5 layers**: defensive structure, data-subject rights, incident response, automated-decision systems, and governance.
- **17 detailed implementation guides** with concrete technology stacks, anti-patterns, verification procedures, and auditable evidence.
- **16 documented real-world cases** of data-protection incidents, including public sources, technical failure classes, relevant legal provisions, and civil-liability mapping.
- **8 Latin American data-protection regimes** mapped to open legal standards.
- A deterministic **Compliance Maturity Index (CMI), levels 0 to 4**.
- **Trilingual interface:** Portuguese, Spanish, and English.
- A fully local architecture with no cookies, no external dependencies, and no user data transmission.

### How to use

SALAT is distributed as a **single self-contained HTML file**.

1. Download `salat.html`.
2. Open it in a modern browser such as Chrome, Firefox, Edge, or Safari.
3. Use the guided questionnaire to describe the system.
4. Generate the technical-legal report with applicable controls, legal references, implementation guidance, and maturity indicators.

> If the repository preview does not execute the interface, download the HTML file and open it directly in the browser. Some mobile or in-app file viewers may display the page without executing JavaScript.

### Technical requirements

- Modern web browser.
- No server required.
- No installation required.
- No internet connection required for core operation.
- Vanilla HTML5, CSS3, and JavaScript (ES6+).
- Zero external runtime dependencies.

### Research scope

SALAT is a research-oriented pre-compliance instrument. It does not replace specialized legal advice, regulatory interpretation, formal certification, or organization-specific security assessment.

Its methodology is based on the translation of open legal standards into technical controls through CNTM/MTNC, with explicit traceability between legal basis, engineering decision, and responsibility allocation.

## Português

### Visão geral

O **SALAT (Software Accountability for Latin America Tool)** é a implementação demonstrativa do **Modelo de Tradução Normativa Computacional (MTNC; em inglês, Computational Normative Translation Model - CNTM)**, método voltado à tradução de standards jurídicos abertos das leis latino-americanas de proteção de dados em decisões de engenharia de software verificáveis e rastreáveis por dispositivo legal.

A ferramenta converte expressões jurídicas abertas, como *"medidas técnicas adequadas"*, em decisões de engenharia concretas e defensáveis. Cada controle é associado a um dispositivo legal específico e a referências técnicas reconhecidas, incluindo NIST, OWASP, ISO e CIS.

### Publicação associada

Karpinski, T. **"Legal Software Architecture in Latin America: A Computational Normative Translation Model for Data Protection and Civil Liability Prevention."** Artigo aceito no **Latin.Science 2026, Latinoware 2026**.

A referência bibliográfica definitiva e o DOI serão adicionados após a publicação.

### O que o SALAT inclui

- **45 controles** organizados em **5 camadas**: estrutura defensiva, direitos do titular, resposta a incidentes, sistemas de decisão automatizada e governança.
- **17 guias de implementação** detalhados, com stacks tecnológicas, anti-padrões, procedimentos de verificação e evidências auditáveis.
- **16 casos reais documentados** de incidentes de proteção de dados, com fontes públicas, classes de falha técnica, dispositivos jurídicos relevantes e atribuição de responsabilidade civil.
- **8 regimes latino-americanos de proteção de dados** mapeados a standards jurídicos abertos.
- **Índice de Maturidade em Conformidade (IMC), níveis 0 a 4**.
- **Interface trilíngue:** português, espanhol e inglês.
- Arquitetura local, sem cookies, sem dependências externas e sem transmissão dos dados inseridos pelo usuário.

### Como usar

O SALAT é distribuído como **um único arquivo HTML autossuficiente**.

1. Baixe `salat.html`.
2. Abra o arquivo em um navegador moderno, como Chrome, Firefox, Edge ou Safari.
3. Preencha o questionário guiado com as características do sistema.
4. Gere o relatório técnico-jurídico com controles aplicáveis, referências legais, orientações de implementação e indicadores de maturidade.

> Se a visualização do repositório não executar a interface, baixe o arquivo HTML e abra-o diretamente no navegador. Alguns visualizadores móveis ou navegadores internos de aplicativos exibem a página sem executar o JavaScript.

### Requisitos técnicos

- Navegador moderno.
- Sem servidor.

### Escopo de pesquisa

O SALAT é um instrumento de pré-conformidade orientado à pesquisa. Ele não substitui assessoria jurídica especializada, interpretação regulatória, certificação formal ou avaliação de segurança específica da organização.

Sua metodologia baseia-se na tradução de standards jurídicos abertos em controles técnicos por meio do MTNC/CNTM, com rastreabilidade explícita entre base legal, decisão de engenharia e atribuição de responsabilidade.
