## English

### Overview

**SALAT (Software Accountability for Latin America Tool)** is the demonstrative
instantiation of the **MTNC (Modelo de Tradução Normativa Computacional /
Computational Normative Translation Model)** — a method that converts open legal
standards from Latin American data-protection laws into verifiable, article-traceable
architectural decisions.

The tool translates deliberately open legal expressions (such as *"adequate technical
measures"*) into concrete, defensible engineering decisions, each mapped to a specific
article of law and to a recognized international standard (NIST, OWASP, ISO, CIS).

### How to use

SALAT is a **single, self-contained HTML file**. There is nothing to install.

1. **Download** the file `salat.html` from this repository.
2. **Open it** by double-clicking, or drag it into any modern web browser
   (Chrome, Firefox, Edge, Safari).
3. It runs **fully offline**. No data leaves your device; there are no network calls,
   no cookies, and no external dependencies.

> The repository link shows a **file listing**, not the running tool. Download the
> HTML file and open it locally to interact with SALAT.

### What is included in the tool

- **45 controls** organized in **5 layers** (defensive structure; data-subject rights;
  incident response; automated-decision systems; governance).
- **17 detailed implementation guides**, each with concrete technology stacks and
  explicit anti-patterns.
- **16 real, documented cases** of data-protection incidents, each with a verifiable
  public source, the technical failure, the violated legal provision, and the
  attribution of civil liability.
- **8 Latin American data-protection laws** articulated with their open standards.
- A deterministic **Compliance Maturity Index (0–4)**.
- **Trilingual interface**: Portuguese, Spanish, English.

### Technical requirements

- Any modern web browser. No server, no installation, no internet connection required.
- The tool is written in vanilla HTML5, CSS3, and JavaScript (ES6+), with **zero
  external dependencies** — a deliberate choice for portability, auditability, and
  privacy by design.

## Português

### Visão geral

O **SALAT (Software Accountability for Latin America Tool)** é a instanciação
demonstrativa do **MTNC (Modelo de Tradução Normativa Computacional)** — método que
converte standards jurídicos abertos das leis de proteção de dados da América Latina
em decisões arquiteturais verificáveis e rastreáveis por artigo de lei.

A ferramenta traduz expressões legais deliberadamente abertas (como *"medidas técnicas
adequadas"*) em decisões de engenharia concretas e defensáveis, cada uma mapeada a um
artigo de lei específico e a um padrão internacional reconhecido (NIST, OWASP, ISO, CIS).

### Como usar

O SALAT é um **arquivo HTML único e autossuficiente**. Não há nada a instalar.

1. **Baixe** o arquivo `salat.html` deste repositório.
2. **Abra-o** com dois cliques, ou arraste-o para qualquer navegador moderno
   (Chrome, Firefox, Edge, Safari).
3. Ele funciona **totalmente offline**. Nenhum dado sai do seu dispositivo; não há
   chamadas de rede, cookies nem dependências externas.

> O link do repositório mostra uma **lista de arquivos**, não a ferramenta em execução.
> Baixe o arquivo HTML e abra-o localmente para interagir com o SALAT.

### O que a ferramenta inclui

- **45 controles** organizados em **5 camadas** (estrutura defensiva; direitos do
  titular; resposta a incidentes; sistemas de decisão automatizada; governança).
- **17 guias de implementação** detalhados, cada um com stack técnica concreta e
  anti-padrões explícitos.
- **16 casos reais documentados** de incidentes de proteção de dados, cada um com
  fonte pública verificável, falha técnica, dispositivo legal violado e atribuição
  de responsabilidade civil.
- **8 legislações latino-americanas** articuladas com seus standards abertos.
- Um **Índice de Maturidade em Conformidade (0–4)** determinístico.
- **Interface trilíngue**: português, espanhol e inglês.

### Requisitos técnicos

- Qualquer navegador moderno. Sem servidor, sem instalação, sem internet.
- Escrito em HTML5, CSS3 e JavaScript (ES6+) puros, com **zero dependências externas**
  — escolha deliberada em prol de portabilidade, auditabilidade e privacidade desde a
  concepção.
